# Overview

The **AI Agent Traceability** widget shows the trace flow of an AI investigation run, and opens from **AI Investigation Details**, **AI Assistant** chat bot and similar other widgets. It lists every step of the run as an expandable tree, with the total step count and total run time. Selecting a step shows its status, duration, input and output, and metadata such as the model, provider, token usage, and MCP server name. You can search the steps and refresh the trace flow.

> [!Note]
> This widget is part of the **FortiAI** solution pack - `v6.1.0` and later - and is installed with it. The widget displays trace data for a run started from the **AI Investigation Details** widget, which supplies the trace ID. Therefore, the widget requires the FortiAI solution pack to function.

For information, see the section **Using the AI Agent Traceability** in [FortiAI](https://github.com/fortinet-fortisoar/solution-pack-fortinet-advisor/blob/release/6.1.0/docs/ai-agent-traceability.md) solution pack documentation.
